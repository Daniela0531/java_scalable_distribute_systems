# Scalable distributed systems

## Задача 1
Необходимо создать REST-сервис, реализующий два эндпоинта – POST для добавления записи в хранилище и 
GET для получения значения по заданному ключу.  

Можно реализовать на любом языке, рекомендуется использовать Java/Kotlin с Spring MVC (Spring Boot MVC).
Для хранения записей следует использовать HashMap.  

**Эндпоинты**:  

POST /put:  
Принимает ключ и значение через URL-параметры для сохранения в map.
Пример запроса: /put?key=имя&value=значение  

GET /get:  
Принимает значение ключа через URL-параметр и возвращает соответствующее значение из map.
Пример запроса: /get?key=имя  

Тестирование:  
Проверьте работу сервиса с помощью Postman, cURL или аналогичных инструментов, убедившись, что:  
PUT-запрос корректно сохраняет данные.  
GET-запрос по заданному ключу возвращает соответствующее значение.  

Полезные ресурсы:  
Building a RESTful Web Service  
Как работать с Curl  
REST API для приложения со Spring Boot, Kotlin и Gradle

## Решение
Написан сервис.
Для запуска необходимо запустить класс Application.

Выполнение запросов:  

GET:
curl -X GET 'http://localhost:8080/get?key={key}'  

PUT:
curl -X PUT 'http://localhost:8080/put?key={key}&value={value}'
